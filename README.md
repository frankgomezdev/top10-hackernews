# Hacker News Top 10

This repository provides a solution to the exercise on React Practice which is to build a page that displays the top 10 articles from Hacker News.

Users can:

- View the top 10 articles from Hacker News
- See each article's title, score, and author
- Click through to the original article

Exercise: [https://reactpractice.dev/exercise/show-top-10-articles-from-hacker-news/]
